# NoBloat Dimmer

A free Windows utility that lets displays go darker than their normal minimum brightness.

No account. No tracking. No subscription. No bundled junk.

## Main features

- Global and per-display dimming
- Brightness below the monitor’s normal minimum
- 5% keyboard adjustments
- Blackout mode
- Emergency restore with `Alt + Shift + 0`
- Local preferences
- No accounts or tracking

## Installation

1. Download the release ZIP.
2. Extract the files.
3. Run `NoBloatDimmer.exe`.

Windows may show an **Unknown publisher** warning because the current beta is not yet code signed. Download only from the official NoBloatTools website or this GitHub repository.
