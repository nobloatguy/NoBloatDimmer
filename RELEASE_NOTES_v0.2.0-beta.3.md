# NoBloat Dimmer v0.2.0 Beta 3

This update keeps the existing NoBloat Dimmer layout and adds requested window, keyboard, and personalization controls.

## Added

- Full screen and restore button in the title bar
- Double click the title bar to enter or leave full screen
- Drag the full title bar to move the window
- Freely resize the window by dragging any edge or corner
- Window size presets remain available alongside free resizing
- Left and right arrow keys change a focused slider by 5%
- Quick Reset settings in the gear section with Enter, R, and Backspace choices
- The selected Quick Reset key restores every display to 0% while the app window is active
- Keyboard focused buttons have a visible accent outline
- Blackout button cycles from blackout to 50% and then to 0% when clicked
- The website arrow includes a subtle SITE label and clearer tooltip
- Proper rounded content clipping prevents square panels from bleeding through the window corners
- Hidden J bae bae Birthday Mode button adds an animated rainbow accent and toggles back to the selected theme

The release script produces `NoBloatDimmer-win-x64.zip`, the stable asset name used by NoBloatTools.com.

## Existing safety controls

- Alt + Shift + 0 restores every display to 0%
- Full blackout remains unavailable if the emergency shortcut cannot register
- Settings remain local to the device
